# Arab Music
Arabic RTL music site. Plain HTML/CSS/JS, no build step. Cloudflare Pages: build command empty, output directory `/`.
The UI only calls `musicSourceAdapter.js`. Audius is the temporary source; `albumaty*.js` are disabled placeholders.
To enable Albumaty you need: official API docs (URLs, response format) or a written agreement from the rights holders, plus any API key (kept in a Cloudflare Worker).
